# _meta.json 模板

当你评估一个 skill 发现它缺少 `_meta.json` 时，可以提供这个模板：

```json
{
  "slug": "skill-name",
  "version": "1.0.0",
  "author": "your-name",
  "trigger_words": [
    "关键词1",
    "关键词2",
    "关键词3"
  ]
}
```

## 触发词设计指南

### 好触发词的特征

| 特征 | 示例 | 说明 |
|------|------|------|
| 精准 | "头脑风暴" | 明确指向 skill 功能 |
| 有变体 | "brainstorm" | 包含英文 |
| 带前缀 | "帮我头脑风暴" | 减少误触 |
| 长度合适 | 3-8 字 | 太短容易误触，太长用户记不住 |

### 坏触发词的特征

| 特征 | 问题 |
|------|------|
| "帮我" | 过于通用，几乎任何请求都包含 |
| "test" | 英文通用词 |
| "help" | 太短，容易误触 |
| 单独的字 | 如"测"、"评" |

### 示例：不同类型 skill 的触发词

**头脑风暴类：**
```json
{
  "trigger_words": [
    "头脑风暴",
    "brainstorm",
    "创意发散",
    "帮我头脑",
    "设计方案讨论"
  ]
}
```

**营销类：**
```json
{
  "trigger_words": [
    "营销 ideas",
    "marketing",
    "推广策略",
    "增长思路"
  ]
}
```

**设计类：**
```json
{
  "trigger_words": [
    "设计页面",
    "帮我设计",
    "build a",
    "design a"
  ]
}
```
