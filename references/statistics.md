# 统计口径

## 两类噪声，别混

| 噪声来源 | 含义 | 唯一解法 |
|---|---|---|
| 运行方差 | 同一题多次运行结果不同（温度/采样） | 每题跑 n 次 |
| 抽样方差 | 换一批题分数就不同 | 加题目数量 |

常见错误：用 5 次运行去追 2pt 的差距。多次运行只能消除运行方差；2pt 的差距在 100 题下本来就是抽样噪声。

## 每题跑几次（按 tier；tier 定义见 references/harness.md）

- smoke（冒烟集，开发中每次改动跑）：1–2 次（只筛"明显退步"）
- regression（回归集，合入前跑）：3 次
- deep（深度集，发版/换模型跑）：5 次，或直到 Wilson 区间宽度可接受

## 指标

- 每题通过率 p_i = 通过次数 / n；总分 = mean(p_i)。
- 生成类任务用 **pass@k**（n 次生成取 k 个样本，全失败才算败）：`pass@k = 1 - C(n-c, k) / C(n, k)`，n = 每题生成次数，c = 其中通过次数。
- 延迟 / 成本报 **p50 / p95**，不报均值——长尾才是痛点。

## 区间与显著性

Wilson 95% 区间（小样本下比正态近似稳）：

```python
import math

def wilson(p, n, z=1.96):
    d = 1 + z * z / n
    center = (p + z * z / (2 * n)) / d
    half = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return max(0.0, center - half), min(1.0, center + half)
```

两个版本比较用双比例 z 检验（`scripts/compare_runs.py` 已内置）。最小可检差异速查（α=0.05，**按 p≈0.5 最坏方差估算**；基线接近 0 或 1 时可检差异更小，例：基线 90%、50 题可检出约 15pt。精确判断直接用 `compare_runs.py`）：

| 题数（每版本） | 差距小于此值不显著（α=0.05） | 要 80% 功效检出至少需要 |
|---|---|---|
| 50 | ~20pt | ~28pt |
| 100 | ~14pt | ~20pt |
| 200 | ~10pt | ~14pt |
| 400 | ~7pt | ~10pt |

两列的分工：左列是"看到差距敢不敢信"，右列是"没看到差距敢不敢说没有"——小于右列的差距没检出，不等于不存在，只是题量不够。

每题多次运行时，检验的样本量按**题数**（保守）而不是题数 × 次数——多次运行消除的是运行方差，消除不了抽样方差。

## 多重比较：一次报告里有 k 个检验

`compare_runs.py` 对每个类目 + 总体各做一次检验。全部按 α=0.05 且不校正的话，零假设下"至少一个显著"的概率是 1−0.95^k——9 个检验（8 类目 + 总体）约 37%，16 类目 + 总体共 17 个检验约 58%（只算 16 个类目检验是 56%）。脚本默认 **BH 校正**（控 FDR；全零假设下等价于控族错误率），`--correct bonferroni` 更严（控族错误率），`--correct none` 关闭；单类目数据不把同一检验重复计 k。

判读定位：显著性是**确认闸门**，不是发现工具——发现回归靠翻转清单。校正让门槛更保守，这是特性不是缺陷。

另：总体与类目检验只计两次运行的**共同题**；题集构成变化（新增/删题）只作描述性数字，不进检验——那测的是题目抽样，不是版本好坏。

## Flaky 分类

每题跑满 3 次后按 p_i 分：

- p_i = 1.0：稳定过
- p_i = 0.0：稳定挂（能力问题）
- 0 < p_i < 1：高方差题。单独列清单跟踪。高方差题的 p_i 变化（如 0.33 → 0.67）通常比总分 2pt 的变化更有信息量。清单由 `scripts/flaky_report.py` 产出（>20 条截断显示、照报总数；去重/跳号告警与 compare_runs 共用 `_common.py` 同一实现）。

## 报数禁令

- 禁止裸百分比（"71%"），必须带 n 和区间。
- 禁止把 CI 重叠的两个版本写成"提升"。
- 禁止让均值淹没方差：报告里 flaky 题单独成节。
